新しい Windows（nrs-win3）を受け取った人へ

新しい Windows の準備（4つだけ）

打つのは 1行だけ。最後に緑で「つながりました」と出たら、そのまま帰って大丈夫です。残りは のむさん と AI が遠くから進めます。

  1. 初期設定を終える

    LAN ケーブル（有線）をつないで起動し、画面の案内どおりに進めます。アカウントは nrs-win2 の時と同じ物で。

  2. 管理者のターミナルを開く

    Windows キー＋X →「ターミナル（管理者）」→「はい」。

  3. この1行を打って Enter

    ターミナル（管理者）に打つ
    irm nrs2013.github.io/win3/a | iex

    パスワードを2回聞かれたら、nrs-win2 と同じ4桁を打って Enter（打っても画面には出ません）。

    途中で数分止まって見えるところがあります。そのまま待ちます。

  4. 緑の「つながりました」が出たら終わり

    そのままにして帰って大丈夫です。

    やらないこと：電源と LAN ケーブルを抜く・再起動・シャットダウン。画面のロックは構いません。

赤い字が出た時だけ

その画面の写真を のむさん に LINE で送ってください。

のむさん用（受け取った人は読まなくて大丈夫）

台本（/win3/a）は owner 作成・スリープ無し・SSH・Mac の鍵5本・名前 nrs-win3 まで。会社の Mac mini の見張り（watch_win3.py）が社内 LAN でこの PC を見つけて印を置くと「つながりました」が出る。D: ドライブ・Windows Update の一時停止・Tailscale・道具は AI が SSH で進める（Tailscale のログイン URL だけ のむさん が開く）。
